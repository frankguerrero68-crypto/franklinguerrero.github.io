LOCAL SETUP

1. Extract this ZIP file.
2. Open the extracted folder.
3. Open the assets folder.
4. Copy your headshot into assets and name it exactly profile.jpg.
5. Copy an airport image into assets and name it exactly airport.jpg.
6. Copy your resume PDF into assets and name it exactly resume.pdf.
7. Double-click index.html.
8. After replacing a file, press Ctrl+F5 in your browser.

You do not need to edit the HTML for these three files.

WINDOWS WARNING
Turn on File name extensions: File Explorer > View > Show > File name extensions.
This prevents accidental names such as profile.jpg.jpg.
